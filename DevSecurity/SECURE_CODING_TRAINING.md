# Developer Security Training Plan
- Secure coding fundamentals (OWASP Top 10) — onboarding + annual refresh
- OWASP Top 10 for IoT/Industrial IoT — required for anyone touching sensor ingestion code
- SAFe Secure Coding practices — integrated into sprint Definition of Done
- Design-phase security review: STRIDE threat modeling required for any new service/API
- Privacy by design: data minimization review before new data fields are added
